# Формы — мои английские слова

Веб-приложение для изучения 200 неправильных глаголов из предоставленного PDF и собственных слов.

- Добавляйте глаголы с формами V1, V2 и V3 и существительные с переводом.
- В карточках можно выбрать все слова или отдельную часть речи.
- Общая проверка перемешивает исходные и добавленные глаголы с существительными. Для существительных нужно перевести слово с русского на английский.
- Ошибки возвращаются в повторение. Прогресс сохраняется в браузере на текущем устройстве.
- В разделе «Словарь» можно скачать резервную копию и загрузить её на другом устройстве.

Откройте `index.html` локально или пользуйтесь опубликованной версией. Список исходных глаголов составлен по PDF Englishweb.ru.
